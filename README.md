# ระบบประเมินการสัมภาษณ์ผู้ขอรับทุนศึกษา BAFS Group (Real-Time Committee Assessment)

ระบบเว็บแอปพลิเคชันสำหรับคณะกรรมการสัมภาษณ์ผู้ขอรับทุนศึกษาของกลุ่มบริษัท BAFS Group พัฒนาขึ้นตามเกณฑ์และโครงสร้างข้อมูลจากไฟล์ `20260817 แบบประเมินการสัมภาษณ์ผู้ขอรับทุนศึกษา.xlsx` รองรับการประเมินพร้อมกัน 5 ท่าน พร้อม Dashboard สรุปผลคะแนนแบบ Real-time และการส่งออกข้อมูล Excel / PDF

---

## 🚀 วิธีการเปิดใช้งาน (2 วิธีที่สะดวกที่สุด)

### วิธีที่ 1: เปิดใช้งานแบบ Standalone บนเครื่องเดียว (เร็วที่สุด)
- ดับเบิ้ลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานบนเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari)
- สามารถเปิดหลายหน้าต่าง (Windows / Tabs) สำหรับกรรมการแต่ละท่านและหน้า Dashboard โดยข้อมูลจะ **ซิงค์เชื่อมต่อกันแบบ Real-Time อัตโนมัติทันที** ผ่าน `BroadcastChannel API`

### วิธีที่ 2: เปิดใช้งานแบบเชื่อมต่อหลายอุปกรณ์ในห้องประชุม (iPad / แท็บเล็ต / โน้ตบุ๊ก)
1. ดับเบิ้ลคลิกไฟล์ `start.bat` หรือคลิกขวาที่ `server.ps1` แล้วเลือก *Run with PowerShell*
2. ระบบจะแสดง IP สำหรับเชื่อมต่อ เช่น `http://192.168.1.xxx:8080/`
3. ให้คณะกรรมการในห้องประชุมที่ต่อ Wi-Fi เดียวกัน เปิดลิงก์ดังกล่าวบน iPad หรืออุปกรณ์ของตนเอง
4. ข้อมูลการลงคะแนน ข้อคิดเห็น และมติจะซิงค์เข้าเครื่องแม่ข่ายและแสดงผลบนจอ Dashboard สรุปผลทันที

## 📋 ฟังก์ชันและคุณสมบัติเด่น

1. **หน้าจอประเมินสำหรับกรรมการ 5 ท่าน**:
   - `EM`
   - `MD-BPT`
   - `MD-TARCO`
   - `MD-BPS`
   - `HZ`
2. **เกณฑ์การประเมิน 6 หมวด (น้ำหนักรวม 100 คะแนน)**:
   - หมวด 1: ความสอดคล้อง สนับสนุนต่อกลยุทธ์องค์กร (25%)
   - หมวด 2: ความผูกพัน และตั้งใจพัฒนาองค์กรในระยะยาว (25%)
   - หมวด 3: แรงจูงใจและเป้าหมายการศึกษา (15%)
   - หมวด 4: ภาวะผู้นำและบทบาทแบบอย่างที่ดีในการทำงาน (15%)
   - หมวด 5: การวางแผน ความรับผิดชอบ ไม่กระทบงาน/ทีม (10%)
   - หมวด 6: การมีส่วนร่วมในกิจกรรมและโครงการขององค์กร (10%)
3. **การคำนวณคะแนนตามสูตร Excel แม่นยำ 100%**:
   - คะแนนถ่วงน้ำหนักแต่ละหมวด = `(คะแนนดิบ 1-5 ÷ 5) × ค่าน้ำหนัก`
   - คำนวณคะแนนรวมและคะแนนเฉลี่ยสุทธิแบบ Real-time
4. **บันทึกข้อคิดเห็นเชิงคุณภาพ 4 มิติ**:
   - 🌟 จุดเด่นหรือจุดแข็งของพนักงาน
   - ⚠️ จุดอ่อนของพนักงานหากผ่านสัมภาษณ์
   - 🚀 ความคิดเห็นเกี่ยวกับความมุ่งมั่นที่จะกลับมาพัฒนาองค์กร
   - 💬 ข้อคิดเห็นอื่นๆ (ถ้ามี)
   - ⚖️ มติของกรรมการ: **ผ่าน (Pass)** หรือ **ไม่ผ่าน (Fail)**
5. **Real-time Live Consensus Dashboard**:
   - Status Tracker แสดงสถานะกรรมการแต่ละท่าน (ส่งคะแนนแล้ว / กำลังประเมิน / ยังไม่เริ่ม)
   - ตาราง Matrix เปรียบเทียบคะแนนกรรมการทุกคนกับคะแนนเฉลี่ย
   - Radar Chart แสดง Competency Profile 6 ด้าน
   - Bar Chart เปรียบเทียบคะแนนรวมของกรรมการ
   - สรุปรวมข้อคิดเห็นเชิงคุณภาพในหน้าเดียว
6. **ส่งออกไฟล์ Excel (.xlsx)**:
   - ส่งออกข้อมูลเป็นไฟล์ Excel ที่มีโครงสร้างชีตครบถ้วน (`Summary`, `EM`, `MD-BPT`, `MD TARCO`, `MD-BPS`, `HZ`) ตรงตามเทมเพลตเดิม
7. **พิมพ์รายงาน / บันทึกเป็น PDF**:
   - รองรับการสั่งพิมพ์ A4 จัดหน้าสวยงามเป็นระเบียบพร้อมใช้ประกอบรายงานการประชุม

## 📁 โครงสร้างไฟล์ในระบบ

- `index.html` — หน้าเว็บแอปพลิเคชันหลัก
- `app.js` — Core Logic การคำนวณคะแนน, Real-time Sync, Dashboard และ Excel Exporter
- `data.js` — เกณฑ์การประเมิน, คำอธิบายรูบริก, น้ำหนักคะแนน และรายชื่อกรรมการ
- `server.ps1` — Local Web Server & REST API
- `start.bat` — One-click launcher สำหรับรันเซิร์ฟเวอร์
